# 💼 المساعد المالي والتنفيذي والضريبي الذكي
### Smart Operations & Jordanian Tax Compliance Assistant

نظام محاسبي وإداري ذكي مدعوم بنماذج الذكاء الاصطناعي متعددة الوسائط (Gemini AI)، مصمم خصيصاً للأنشطة التجارية في المملكة الأردنية الهاشمية (المطاعم، التجزئة، المقاولات، الخدمات، الصيدليات وغيرها). يتيح النظام إدارة العمليات النقدية اليومية، وتدقيق الفواتير آلياً، ومطابقة ضريبة المبيعات وفق متطلبات نظام الفوترة الوطني الأردني (**JoFotara**).

---

## 🌟 أبرز المميزات (Key Features)

1. **استيعاب متعدد الوسائط عبر تيليجرام (Multi-Modal Ingestion):**
   - استقبال وتدقيق فواتير الزبائن والموردين عبر الصور (OCR)، الرسائل النصية، والرسائل الصوتية (Voice Notes).
   - استخراج تلقائي لجميع البنود، الأسعار، الضرائب، وطرق الدفع.

2. **التصنيف الذكي بهوية المنشأة وفروعها (Dynamic Identity Awareness):**
   - حقن هوية المنشأة وأسماء فروعها ديناميكياً لتمييز فواتير المبيعات للزبائن عن فواتير مشتريات وتوريدات البضاعة من الموزعين.

3. **التدقيق المالي الثلاثي (3-Way Arithmetic Reconciliation):**
   - مطابقة حسابية صارمة: الإجمالي = المجموع الفرعي + الضريبة - الخصم.
   - مطابقة وسائل الدفع: الإجمالي = الكاش + البطاقات + كليك (CliQ) + تطبيقات التوصيل.
   - رصد العجز والفروقات واكتشاف الأخطاء المحاسبية وتوجيهها للمراجعة.

4. **الامتثال الضريبي الأردني (JoFotara Compliance):**
   - تصنيف الضريبة العامة على المبيعات (16%، معفى، صفري).
   - حساب ضريبة المخرجات وضريبة المدخلات وصافي الالتزام الضريبي.
   - رصد الفواتير عالية المخاطر (غير المعززة بالرقم الضريبي للمورد).
   - تقرير إقرار ضريبي جاهز للطباعة المباشرة والتصدير (Printable Tax Report).

5. **لوحة تحكم تنفيذية تفاعلية (Executive Dashboard):**
   - مؤشرات أداء فورية (KPIs) للتدفق النقدي، المبيعات الفعلية، والمصروفات.
   - رسوم بيانية تفاعلية لتوزيع طرق الدفع وحركة الإيرادات والمصروفات.
   - شريط بحث وتصفية متقدم حسب الفرع، النوع، الحالة، والكلمات المفتاحية.
   - نافذة مراجعة واعتماد تفاعلية مع إمكانية تعديل الأرقام والبنود يدوياً قبل الاعتماد.

6. **تصدير كشوفات Excel / CSV:**
   - تصدير كامل العمليات المالية بترميز UTF-8 BOM متوافق بنسبة 100% مع Microsoft Excel باللغة العربية على ويندوز.

7. **الجدولة الآلية للتقرير الصباحي (Automated Morning Briefing):**
   - إرسال ملخص تنفيذي يومي تلقائي إلى محادثة تيليجرام للمالك في الموعد المحدد.

## 🛠️ هيكلية النظام والتقنيات المستخدمة (Tech Stack)

- **Backend:** FastAPI (Python 3.11+)
- **Database / ORM:** SQLite / SQLAlchemy 2.0
- **AI Vision & Audio Engine:** Google Gemini REST API (Multi-model fallback chain)
- **Frontend:** Vanilla JavaScript (ES6+), HTML5, Tailwind CSS, Chart.js
- **Bot Integration:** Telegram Bot API (HTTP Long-Polling & Scheduler)

## 🚀 طريقة التثبيت والتشغيل (Quick Start)

### 1. استنساخ المستودع (Clone)
`ash
git clone https://github.com/cytoarenaai2-cpu/my_smart_ops.git
cd my_smart_ops
`

### 2. إنشاء البيئة الافتراضية وتثبيت المتطلبات
`ash
python -m venv venv
# لنظام ويندوز:
.\venv\Scripts\activate
# لنظام لينكس / ماك:
source venv/bin/activate

pip install -r requirements.txt
`

### 3. إعداد المتغيرات البيئية (.env)
قم بإنشاء ملف .env بنسخ .env.example:
`ash
copy .env.example .env
`
وقم بملء المفاتيح الخاصة بك:
`ini
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
GEMINI_API_KEY=your_gemini_api_key
DATABASE_URL=sqlite:///./smart_ops.db
DEFAULT_CURRENCY=JOD
`

### 4. تشغيل النظام
- **على نظام ويندوز:** انقر نقراً مزدوجاً على start.bat أو نفّذ:
`ash
python run.py
`
- تصفح لوحة التحكم عبر المتصفح:
👉 http://127.0.0.1:8000/dashboard
